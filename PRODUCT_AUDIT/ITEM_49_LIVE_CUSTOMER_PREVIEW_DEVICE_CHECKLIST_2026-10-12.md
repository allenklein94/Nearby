# Item 49 - live Customer Preview while making an offer - device checklist (2026-10-12)

Status: BUILT, NOT DEVICE-VERIFIED. Record device, OS, appearance mode (light/dark), language and the result of every check.
Run on a real phone (iOS and Android) AND the business website in a real browser. A real business account with an open
opportunity is needed; send at least one offer to a real customer account on a second phone for check 7.

| # | Check | Result |
|---|-------|--------|
| 1 | Open Make an Offer: with no description typed, NO preview shows (no empty card, no placeholder). | |
| 2 | Type a description: the "Customer preview" card appears directly above Send Offer, with the screened logo (or no logo), business name, "Heard your request" and the status line. | |
| 3 | Build "20% off tonight": pick Discount, type 20, a title, an end time today, a 5-9 PM window. Each change shows in the preview at once (headline "20% OFF", title, when line), with no lag while typing. | |
| 4 | Pick a saved creative, then a new photo from the phone, then a video: the preview shows each the same way the customer card does (video: tap-to-play, no autoplay). | |
| 5 | A piece Send would refuse is absent from the preview: a discount above the business's limit, an end time already passed, a window with only one end. Tapping Send Offer then shows the same fix it always did. | |
| 6 | There is no separate "Preview offer" / "Back to edit" step: Send Offer sends; Cancel closes; a draft is kept as before. | |
| 7 | On the customer's phone, the received offer card reads the same as the preview did (same lines, same order, same media). | |
| 8 | Keyboard: the preview never covers the field being typed in; scrolling to Send Offer passes the preview (iOS + Android). | |
| 9 | Light and dark mode: the preview card and the disabled "I'll take this one" are readable. | |
| 10 | Screen reader: the preview's disabled button announces as the preview of the customer's button, not as an action. | |

Not covered by this item: AI screening of the content (needs Anthropic credit), the one-tap Standard availability /
Alternative responses (fixed text, no preview, unchanged).
